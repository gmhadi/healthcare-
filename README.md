# MediTriage

MediTriage is a Vite and React prototype for a symptom-intake and clinic-booking flow. The interface presents rule-based urgency categories and includes example scenarios; clinic details and scenario data are defined in `src/data/clinics.ts`.

## Run locally

Requirements: Node.js and npm.

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev` (Vite serves on port 3000).
3. Create a production bundle with `npm run build`.
4. Run the TypeScript check with `npm run lint` (`tsc --noEmit`).

The repository includes `.env.example` for the expected `GEMINI_API_KEY` and `APP_URL` environment variables. Configure real values in your local environment or deployment secret manager. Do not commit real credentials. Check the app's runtime configuration before expecting features that call Gemini to work.

## Important limitations

This repository contains a prototype, not a clinically validated diagnostic or emergency-triage service. The urgency result is generated by keyword and severity rules in `src/utils/triageEngine.ts`; it does not replace assessment by a qualified medical professional. Demo scenarios and clinic contact information are static project data and should be independently verified before real-world use. For emergencies, contact local emergency services or go to an emergency department.
