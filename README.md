# MediTriage

MediTriage is a React web app for an AI-assisted symptom triage and clinic appointment flow. The interface includes symptom chat, appointment booking, a confirmation screen, emergency information, and a multi-channel preview.

## Run locally

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

Vite serves the development app on port 3000.

## Available checks

```sh
npm run lint   # TypeScript type-check (tsc --noEmit)
npm run build  # Production build with Vite
```

The package does not currently define a test script.
